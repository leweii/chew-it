# Chew It

> For English, see [README.md](README.md)

一个 Obsidian 插件:用 LLM **分析当前打开的笔记**,在右侧面板生成解读 —— 提炼大纲、解释关键概念、精炼原文,**不改动原文**。打开一篇满是看不懂的概念的文档,选好要分析的视角,点一下,就能得到一份解读。

支持 **Claude (Anthropic)** 与任意 **OpenAI 兼容接口**(含本地 Ollama、第三方代理),自带 key。

## 功能

- **侧边栏面板**,流式逐字以 Markdown 显示分析结果,不污染原文。
- **多个解析视角**以勾选框呈现 —— 勾选要跑的,点 **Chew It**,各视角并行生成,分别进入各自的浏览器风格结果 tab。内置三个(均可在设置里改):
  - **提炼大纲** —— 层级结构与主要论点
  - **概念解析** —— 找出难懂概念并通俗解释
  - **原文精炼** —— 去冗余,保留核心要点与结论
- **每个视角独立的角色设定**(系统提示),可留空(留空则不发送角色)。
- **结果跟着文档走** —— 分析结果按笔记保存,重开 app 或切回该笔记会自动恢复;左上角标靶按钮可跳回被分析的笔记。
- **针对单个 tab 的操作**(`···` 菜单)—— 只重新生成当前 tab,或只导出当前 tab 的结果。
- **导出**当前 tab 结果为 Markdown 笔记或 Canvas(按标题拆成卡片);目标文件已存在时追加。

## 隐私 / 网络说明

Chew It 会把**当前笔记的全文**(含未保存改动)经 HTTPS 发送到你配置的 LLM 提供方,使用你自己的 API Key,不会发往其他任何地方。没有长度限制:超过模型上下文窗口的长文档会自动分段、多次调用模型,并把各段结果拼接连贯 —— 超长文档会产生多次调用,请留意计费。

## 安装

### 社区插件市场(收录通过后)

设置 → 第三方插件 → 浏览 → 搜索 **Chew It** → 安装 → 启用。

### 手动安装

1. 从最新 [release](../../releases) 下载 `main.js`、`manifest.json`、`styles.css`。
2. 拷贝到 `<vault>/.obsidian/plugins/chew-it/`。
3. 重载 Obsidian,在「第三方插件」里启用 **Chew It**。

### 从源码构建

```bash
npm install
npm run build      # 生成 main.js
```

把 `main.js`、`manifest.json`、`styles.css` 拷到库的 `.obsidian/plugins/chew-it/` 目录。开发时用 `npm run dev` 监听重建。

## 使用

1. 在「设置 → Chew It」里选择提供方并填入 API Key(OpenAI 兼容还需 base URL 与模型名)。
2. 打开一篇 Markdown 笔记。
3. 点击左侧栏的 ✨ 图标,或运行命令 **「分析当前文档」**,右侧面板弹出。
4. 勾选要分析的视角,点 **Chew It**,切换结果 tab 阅读。
5. 在某个 tab 的 `···` 菜单里重新生成它或导出它的结果。

## 配置

全部可在「设置 → Chew It」里改:

- **提供方** —— Claude (Anthropic),默认模型 `claude-opus-4-8`;或 OpenAI 兼容接口(自定义 base URL 与模型)。
- **最大输出 tokens** —— 单次分析的输出上限。
- **模型上下文长度(tokens)** —— 按所用模型的上下文窗口填写;超长文档会自动分段多次调用并拼接结果。
- **解析视角** —— 增删、重命名、启用/停用,以及编辑每个视角的角色与提示词。
- **输出模板** —— 配置导出格式(Markdown / Canvas)、目标文件夹、文件名模板(占位符:`{note}` `{label}` `{date}` `{datetime}`)。

界面语言(中文 / English)跟随 Obsidian 的显示语言自动切换。
